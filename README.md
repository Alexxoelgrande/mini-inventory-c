# 📦 Mini Sistema de Inventario en C

## 📝 Descripción del Problema
Programa desarrollado en lenguaje C orientado a la simulación del control de stock e inventario básico para pequeños comercios, permitiendo calcular de manera automática el valor monetario total de los productos almacenados.

## 🚀 Tecnologías y Lenguajes Utilizados
* **Lenguaje:** C (Estándar C99)
* **Compilador recomendado:** GCC
